# Microsoft 365 Copilot Workshop Labs

Practical, hands-on Microsoft 365 Copilot labs created for instructor-led workshops and independent practice.

## Open the labs

**[Open the complete All Labs page](https://aserednytska.github.io/Copilot-Lab/labs/)**

Each lab contains a realistic business case, expected outcome, step-by-step instructions, copyable prompts, synthetic source files, verification questions, limitations and troubleshooting guidance.

## How to use the labs

1. Open the **All Labs** page.
2. Select a lab and read the business case and expected result.
3. Download the synthetic source pack.
4. Follow the instructions and use the prepared prompts.
5. Verify the result against the named sources.
6. Record what Copilot assumed, omitted or interpreted.
7. Confirm what a human must verify or decide before the output can be used.

> The downloadable files contain synthetic workshop information only. Do not replace them with confidential customer, employee or production data.

## Repository structure

- `labs/index.html` — complete lab catalogue
- `labs/lab-*/index.html` — individual lab pages
- `labs/lab-*/downloads/` — participant workbooks, prompt cards and source packs
- `assets/` — shared site styling and scripts

The site is published from the `main` branch using GitHub Pages.
