Synthetic workshop data

Project Northstar is fictional. Participants must use the supplied evidence and keep unsupported or missing information visible.

Case: Project Northstar

A supplier-onboarding pilot is approaching launch. The Steering Committee needs a decision deck, but the source pack contains different dates, incomplete gates, forecasts, proposals and one unsupported financial claim.

EvidenceCurrent positionPresentation treatment
UAT184 of 200 tests complete; four Severity 1 defects open92% complete, but Not ready because the gate is no open Severity 1 defects.
SecurityRetest booked for 10 September; external access not approvedConditional; do not state that security is approved.
Migration215 of 250 supplier records validated86%; final sign-off owner is Not confirmed.
Training36 of 50 users trained72%; below the release gate of 45 of 50.
FinancialsEUR 240k budget; EUR 252k forecastEUR 12k / 5% forecast variance. EUR 35k per week delay cost is unsupported.
RecommendationConditional Go was proposedWorking recommendation only; the committee has not approved it.

Learning objectives

  • define a presentation contract before asking Copilot to create slides;
  • separate authoritative facts, forecasts, proposals and missing evidence;
  • create a deck with standard Copilot in PowerPoint or the optional PowerPoint Agent;
  • audit every visible claim, date and number against its source;
  • change only one approved parameter and protect all unaffected content;
  • improve one weak slide without surrendering design control;
  • generate, verify and source speaker notes;
  • run the final accessibility and decision-readiness checks.

Prerequisites

  • PowerPoint for Microsoft 365 and an eligible Microsoft 365 Copilot licence.
  • Permission to use Copilot with the supplied files.
  • All participant downloads above.
  • Excel desktop or Excel for the web for the source-to-slide audit.
Capability check

Copilot controls, file-based creation, Designer and the PowerPoint Agent can vary by licence, tenant policy, application and rollout. Excel Edit mode and PowerPoint Copilot are required for the no-manual-transfer workflow.

Exercise 1: Define the presentation contract

  1. Open the Participant Workbook.
  2. Record the audience, decision, authoritative source, maximum slides, required tone and prohibited assumptions.
  3. Confirm the eight-slide structure before creating the deck.
Presentation contract
I need an eight-slide steering committee presentation.
Audience: CIO, Finance Director, Operations Director and Programme Sponsor.
Decision required: approve launch, approve conditional launch or delay.
Separate confirmed facts from proposals.
Show unresolved conflicts and use "Not confirmed" when evidence is missing.
Do not invent owners, dates, values or decisions.
First propose the slide structure and evidence required for each slide.

Exercise 2: Build the evidence and contradiction register

  1. Open Source-to-Slide Verification.xlsx in Excel and select Copilot Edit mode.
  2. Reference the Project Brief, Readiness Tracker, Meeting Notes and Change Notice.
  3. Run the direct-edit prompt below and review the planned target ranges.
  4. Apply only when Copilot keeps conflicts separate and does not resolve them by preference.
Evidence-register prompt
Review the attached Project Northstar files. Create an evidence register with:
- claim or metric;
- value;
- effective date;
- source file and source location;
- authority and status;
- conflict;
- missing information;
- confidence.

Create a separate contradiction register. Do not select one conflicting value yourself.

Write the verified rows directly into Evidence Register and Contradictions in the open workbook.
Do not edit any other sheet, formula, validation or formatting.
Show the target ranges and row counts, wait for confirmation, then apply.
Authority rule

The approved Change Notice overrides only the field it explicitly names: the proposed pilot launch date. It does not approve a decision or change any other field.

Exercise 3: Create the draft presentation

Option A: Standard Copilot in PowerPoint

  1. Open Project Northstar Corporate Template.pptx.
  2. Select File > Save As and save a working copy.
  3. Open Copilot from the PowerPoint ribbon or the Copilot button in the lower-right corner.
  4. Select Create presentation from file.
  5. Choose Project Northstar Verified Decision Brief.docx.
  6. Add the creation instruction below.
  7. Review the proposed outline before accepting substantial content.
  8. Save the result as Project_Northstar_Steering_Committee_Draft.pptx.
Create from the verified brief
Create an eight-slide steering committee presentation from the attached Project Northstar Verified Decision Brief.
Use the open Northstar corporate template and preserve its theme and layouts.
Follow the required slide structure.
Separate confirmed facts, proposals and missing evidence.
Add concise speaker notes with a [Sources] block on every slide.
Do not add facts from general knowledge or make the final committee decision.

Option B: PowerPoint Agent in Microsoft 365 Copilot

  1. Open the Microsoft 365 Copilot app.
  2. Open Tools or Agents.
  3. Select PowerPoint.
  4. Attach the Verified Decision Brief.
  5. Paste the same presentation contract and creation prompt.
  6. Create the presentation, then open it in PowerPoint.
  7. Apply the Northstar template if it was not preserved.
  8. Continue with the same evidence audit.
If Option B is missing

Continue with Option A. The Agent is optional and may not appear in every tenant.

Exercise 4: Audit every claim before editing

  1. Open the draft deck and the verification workbook.
  2. In Excel Edit mode, reference the draft presentation.
  3. Ask Copilot to write every visible number, date, status, recommendation and owner directly into Slide Traceability.
  4. Review slide text and speaker notes, then apply only rows supported by the deck.
Evidence-audit prompt
Audit this presentation against the approved source brief.
For every claim, number, date or recommendation, list:
- slide number;
- supporting source;
- support status;
- conflict;
- required correction.

Flag invented numbers, unsupported benefits, assumed decisions and missing conditions.
Write the audit rows directly into Slide Traceability in the open workbook.
Do not modify the presentation or any other workbook sheet.
Show the target range and row count, wait for confirmation, then apply.

Exercise 5: Change one parameter only

Change Notice CN-NS-014 authorises only this replacement:

FieldPrevious valueApproved value
Proposed pilot launch date15 September 202629 September 2026

Step 1: Locate affected text without changing it

One-field impact check
Approved change: Proposed pilot launch date changes from 15 September 2026 to 29 September 2026.
Identify every affected slide and speaker-note location.
Return exact current text, proposed replacement and reason.
Do not modify anything and do not suggest changes to scope, budget, owners, thresholds, risks or recommendation.
  1. Open the verification workbook in Excel Edit mode and reference the draft deck and Change Notice.
  2. Ask Copilot to write every proposed location directly into Change Impact.
  3. Review exact current text, replacement, reason and authority.
  4. Reject unrelated wording, layout or content changes; approve only locations where the launch date is relevant.
Write the impact assessment directly into Excel
You are editing Lab_6_Source_to_Slide_Verification.xlsx in Excel Edit mode.

Using the referenced draft presentation and Change Notice CN-NS-014, write every proposed launch-date replacement into Change Impact.
Create one row per location with slide, location, exact current text, exact replacement, reason, authority and Review Status = Pending.
Do not modify the deck, another workbook sheet, formulas, validation or formatting.
Show the target range and row count, wait for confirmation, then apply.

Step 2: Apply only the approved replacements

Controlled application prompt
Apply only the approved launch-date replacements in the locations I confirm.
Replace 15 September 2026 with 29 September 2026.
Do not rewrite surrounding sentences, change layouts, change other dates, add explanations or reformat the presentation.
Return a before-and-after change log.
If the edit is too broad

Cancel it. Select the exact textbox or slide and ask Copilot again to replace only the approved value. If it still cannot scope the edit, do not apply the change.

Exercise 6: Improve one weak slide

  1. Select the risks and missing-evidence slide.
  2. Ask Copilot to propose three structures without modifying the slide: risk heat map, decision table, or risk–evidence–mitigation matrix.
  3. Compare what each structure clarifies and what it may hide.
  4. Choose one structure.
  5. Ask Copilot to modify only that slide.
  6. Re-run the evidence audit for the changed slide.
Visual options without editing
For the selected risk slide, propose three alternative visual structures:
1. risk heat map;
2. decision table;
3. risk-evidence-mitigation matrix.

For each option explain what becomes clearer and what information may be lost.
Do not modify the slide until I choose an option.

Exercise 7: Generate and verify speaker notes

  1. In PowerPoint, open the View tab.
  2. Open the Notes dropdown.
  3. Select Generate speaker notes for current slide or Generate speaker notes for all slides.
  4. Review the generated notes. Keep useful material and discard unsupported or repetitive text.
  5. Run the source-block prompt below so Copilot adds the blocks directly.
  6. Confirm that no old launch date remains in the notes.
Add source blocks directly in PowerPoint
Add a [Sources] block to the speaker notes of every slide using only NS-01 to NS-04.
Do not change slide content, layout or existing verified notes.
Show the proposed slide-to-source mapping first. Wait for confirmation, then apply.
Final source check
Check every slide and speaker note against sources NS-01 to NS-04.
Return Pass, Correct or Not confirmed for each slide.
Confirm that the old date no longer appears, the new date appears only where relevant and no unrelated content changed.

Exercise 8: Final presentation controls

  1. Open Review > Check Accessibility.
  2. Correct missing alt text, reading order, low contrast and unclear link text.
  3. Confirm the corporate template and slide layouts remain intact.
  4. Confirm the deck has eight slides or fewer.
  5. Confirm that Conditional Go remains a proposal.
  6. Confirm that the final decision remains with the Steering Committee.

Limitations and troubleshooting

ProblemControl
Copilot silently selects one conflicting value.Return both sources, dates and authority; require human resolution.
Rewrite affects an entire textbox.Cancel, select the exact location and rerun a one-value Copilot edit. Do not apply a broad rewrite.
A polished slide makes uncertain evidence look authoritative.Keep proposal, forecast and Not confirmed labels visible.
Corporate branding is not preserved.Start from the supplied template and verify layouts after creation.
A chart contains a wrong number.Compare chart labels and source data with the Readiness Tracker.
Speaker notes repeat or invent context.Ask Copilot to remove unsupported notes and add the exact verified [Sources] blocks; review before applying.
Create from file is unavailable.Use the PowerPoint Agent route. If neither creation route exists, pause this Copilot lab instead of rebuilding it by manual transfer.
PowerPoint Agent is unavailable.Use standard Copilot in PowerPoint; the lab outcome is unchanged.
